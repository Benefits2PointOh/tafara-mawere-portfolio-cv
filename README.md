# Tafara Mawere — Portfolio with CV Download

A static personal portfolio site presenting skills, selected projects, professional information, and a downloadable CV section.

## Contents

- Responsive single-page portfolio layout
- Skills and technology overview
- Selected project previews
- About and contact sections
- CV download area

## Technology

- HTML5
- CSS3
- JavaScript and browser/CDN assets used by the page

## Run locally

Clone the repository and open `index.html` in a browser, or serve the folder with a static web server.

```bash
git clone https://github.com/Benefits2PointOh/tafara-mawere-portfolio-cv.git
cd tafara-mawere-portfolio-cv
```
